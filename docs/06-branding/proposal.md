## 实施顺序

### 1. 接入并验收静态基线

1. 以归档包的 `assets/branding/logo.svg` 为源，检查浅/深背景与标题栏尺寸下三层边缘、光芒和阴影；菜单栏使用包内简化的单色模板图标。
2. 将所需静态资源接入项目运行时；建议品牌源统一放在根目录 `assets/branding/`，前端引用与 Go 嵌入按实际构建路径配置。`build/` 只放构建输出或输入副本。
3. 使用原包 `build/appicon.png` 更新构建输入，并检查现有 `build/appicon.icon`：其中仍引用 `wails_icon_vector.svg`。当前图标任务同时处理 PNG 与 `.icon`，打包还会复制 `build/darwin/Assets.car`，只替换 PNG 不足以保证成品统一。
4. 首先完成 PNG 静态路径：备份后停用默认 `.icon` 输入并调整相关任务，处理旧 `Assets.car`，重新生成和打包，检查 Dock / Finder / 应用内的一致性。原生 `.icon` 外观变体留作后续增强，不在本次强制制作。

归档的 `install.sh` 原样保留供参考，不直接执行：它会写入顶层 `docs/branding/`，不符合本项目阶段目录规则，也未处理现有默认 `.icon` 与 `Assets.car`。后续接入按本方案逐项进行。

### 2. 制作应用内动画预览

沿用 SVG + CSS，按现有 React/TS 结构接入，不新增动画依赖。源文件已有 `pata-card-back`、`pata-card-middle`、`pata-card-front`、`pata-sparkles` 图层。

- 为三道光芒补充独立选择标记，便于依次亮起；不重新绘制卡片轮廓。
- 当前部分柔和投影位于卡片分组之外，制作动画时让投影随对应卡片移动，避免卡片回弹而阴影停在原地。
- 以轻微位移、缩放和透明度变化为主，不改变轮廓、不剧烈旋转；防止描边、滤镜和光芒超出容器被裁切。
- 同页多个 Logo 使用独立的 SVG 定义标识，避免渐变、滤镜引用冲突。

以下为初始调试值，以实际标题栏尺寸和 macOS 观感为准：

| 触发 | 动作 | 时长 | 次数 |
|---|---|---|---|
| 应用首次就绪 | 三层卡片轻微弹出，光芒依次出现 | 约 600ms | 每次启动一次 |
| 记录保存成功 | 卡片轻压后回弹，光芒依次亮起 | 约 700ms | 每次成功最多一次 |

预览放在本目录后续新增的 `preview/`，提供启动、成功、静态模式和浅/深背景切换；可直接离线打开，复用同一设计源。原包 `previews/` 内的图片继续作为静态基线。

### 3. 接入真实业务触发

- 启动：应用主界面首次就绪时播放；Vault 切换、列表刷新和页面导航不重复触发，也不延迟界面可操作时间。
- 成功：先接入 Today 独立 Memo 与 Task 详情评论的保存成功路径。仅在 Go 写入成功后触发；校验失败、写入失败或保存冲突不播放。
- Notes 自动保存、后台扫描和外部文件刷新不触发；避免每次停笔都出现反馈。以后按真实需要扩展 Task 操作，不建设通用动画事件系统。
- 连续成功操作不排队叠加动画；播放中合并反馈，结束后回到原静态形态。成功文本、错误提示和键盘焦点仍由现有业务界面负责。
- 卸载组件或隐藏窗口时停止动画；动画失败仍可正常操作和保存。

### 4. 菜单栏：静态托盘（已实现）

已实现静态单色模板图标，以及点击后显示并聚焦主窗口，保留关窗退出规则（[P6-004 实施记录](implementation-notes.md#p6-004-静态菜单栏托盘与点击聚焦接入)）。**菜单栏逐帧动画明确不做**，不制作帧资源，不引入动画计时器、驻留服务或设置页。只需实机确认菜单栏样式和窗口行为。

### 原生 Dock 图标点击（2026-11-03）

- 启动应用或点击底部 Dock 图标唤起已运行的 Pata 时，用当前应用图标播放约 660ms 的轻压、回弹和小幅摆动，结束后恢复系统原图标。应用内 Logo 动画沿用原行为。
- 复用系统原图标与 SwiftUI 关键帧时间线，原生 Dock 绘制只在播放期间刷新；快速连点不排队，退出时清理。窗口唤起交还 macOS 默认处理，包括恢复最小化窗口。
- 系统开启“减少动态效果”时跳过动画；播放中开启则立即还原。不增加声音、设置或持续动画。
- 验证：独立原生应用通过系统重新打开事件验证了启动、Dock 图像帧变化、快速连点、重复播放、最小化窗口恢复、结束及退出还原；使用实际 `DockIconAnimator`，不读取业务资料库。当前验证环境“减少动态效果”为关闭状态，未修改系统设置。

## 辅助功能与产品边界

遵循 [UI 规范](../01-validate/ui.md) 与 [macOS 原生体验准则](../01-validate/macos-native.md)。应用内响应 `prefers-reduced-motion`，开启时立即恢复静态，不等待动画结束；动画元素不抢焦点、不朗读重复成功信息。

仅 Today / Tasks / Notes 三主导航；不加入动画设置页面、声音、Dock 持续动画、提醒、CLI/MCP/AI 或新的数据结构。深色 PNG 是独立资源，不代表 Dock 自动切换外观；Liquid Glass 和 Icon Composer 原生变体保持可选。

## 应用内 Logo 交互动效

应用内 Logo 使用品牌原始分层图，采用透明背景，仅保留三层卡片和三个黄色光点。鼠标经过、点击及键盘 Enter / Space 触发：卡片轻压、错层弹开、回落；三个黄色光点沿自身朝向依次射出，再收回原位，约 820ms 完成。整体位置和键盘焦点始终不动。沿用 SVG、CSS 与动画控制器，不新增依赖、声音或设置项。

- [x] 侧栏和收起后的顶栏均提供 Logo 按钮，点击或鼠标经过均可触发，不会拖动窗口或跳转页面。
- [x] 鼠标经过与点击均具备防抖防重冷却，动画进行中或冷却期内不被打断重播；侧栏切换重新绑定当前 Logo，启动动画不因切换重复播放。
- [x] 开启减少动态效果时保持静态；窗口隐藏与组件卸载停止动画。
- [x] 自动化测试、生产构建、macOS 打包与签名通过；原生应用验证静止形态、卡片回弹、光点射出收回、侧栏/顶栏切换、防抖与键盘触发。
