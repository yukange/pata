# Idea — 阶段 10：统一应用设置

> **状态：设计已确认，待实施。** 在现有主窗口中集中管理主题、Vault 与语音转写凭证；阶段 11 才实现音频上传与转写。本阶段仅调整与设置直接相关的交互，不重构 Today / Tasks / Notes。

## 为什么要做

当前主题切换（三个图标）和 Vault 操作（目录菜单、重新扫描、更换目录）分散在主界面侧边栏底部；阶段 11 又需要配置一次阿里云百炼 API Key。它们都是低频配置，继续散落会占据日常工作空间。

把这些能力放在一个辅助设置界面，侧边栏只留单个设置入口，能让用户专注于 Today、Tasks 和 Notes。设置承载配置，不成为新的业务导航或独立窗口。

## 用户体验

1. 在侧边栏底部点击**设置齿轮**，进入主窗口内的**单页设置**；可以返回原来的 Today、Tasks、Notes 或标签视图，不丢失导航上下文。
2. 设置页依次呈现三个简洁分区：
   - **外观**：主题「跟随系统 / 浅色 / 深色」，选择后立即生效并能在重启后保持；跟随系统时响应 macOS 深浅色变化。
   - **存储**：当前 Vault 路径、**更换目录**、**重新扫描**、**在 Finder 中打开**。不增加多 Vault/工作区切换。
   - **语音转写**：展示「阿里云百炼 / Qwen-Audio 3.1 / 北京地域」只读说明；唯一需填写的云服务配置是 **API Key**，使用 Vault 外的本机私有 `asr.json` 保存，可重新配置。
3. 日常侧边栏不再常驻主题三按钮，也不再放用于配置的 Vault 下拉菜单，取而代之的是一个设置入口。
4. **首启缺少 Vault** 时，主界面仍直接引导选择目录，不强迫先寻找设置。**Vault 出错或有健康问题** 时，主界面仍提供明确状态/异常提示，不把故障信息藏到设置内。
5. 阶段 11 发起音频转写但未配置 Key 时，可引导打开本页「语音转写」分区，保存后返回原流程。
6. 从编辑中的 Note（或打开的任务详情）进入设置，返回时仍在原来的内容位置，不丢失草稿；优先保留滚动位置与编辑光标，无法可靠保留时至少恢复同一对象与安全保存的文本。Vault 健康警告从主界面仍能直接打开现有的详细错误视图，设置页仅负责修复操作。

## 本阶段交付

- **一个设置入口与一页设置内容**；不新增主导航、独立设置窗口、多级设置侧栏。
- **主题管理迁移**：复用已有主题切换能力，迁入设置页并保留选择；从侧边栏底部移除三个主题按钮。
- **Vault 管理迁移**：复用已有更换目录/重新扫描逻辑，迁入设置页，补充 Finder 打开操作；原 Vault 是唯一工作空间且用户文件不可丢弃。主界面保留首启引导、健康和严重错误提示。
- **ASR 凭证配置**：API Key 输入、本机文件保存（目录 `0700`、文件 `0600`，原子替换）、已配置状态、更换；地域固定华北 2（北京），模型固定 `qwen-audio-3.1-asr-flash-filetrans`。
- **安全与回归**：设置页出入遵守已有未保存草稿保护，尽可能恢复编辑光标和滚动位置；Vault 健康提示入口与现有详情视图不回退，主题切换、文件与搜索、现有菜单/列表不回退。

## 不做

- 不做独立设置窗口、四级分类导航、账户体系、云同步、多个 Vault、通用云服务管理器、主题编辑器或自定义配色。
- 不做地域/模型/供应商选择、热词配置、配额面板、API 测试连接按钮。
- 不将首启 Vault 引导、主界面健康异常提示一并隐藏；也不借迁移重构 Vault 业务存储、索引或已有文件列表。
- 本阶段不实现 MP3 上传、转写、逐字稿编辑与播放器；这些属于阶段 11。
