## 一、单页设置结构

设置在**现有 App 主窗口内容区域**打开，不新开 macOS 设置窗口、Modal 或「设置专区」侧栏。侧边栏底部只保留一个可见的**齿轮设置入口**，可选提供 macOS 常用 `⌘,` 快捷键；快捷键不能成为唯一入口。

| 分区 | 展示与操作 | 关键约束 |
|---|---|---|
| 外观 | 「主题」：跟随系统 / 浅色 / 深色；自定义 RGB 强调色 | 复用现有三种状态，改变立即生效；选择持久化于 App 级偏好，重启后恢复；跟随系统时响应系统切换 |
| 存储 | 当前 Vault 路径；更换目录、重新扫描、在 Finder 中打开 | 单 Vault；复用阶段 1～9 的已有安全流程，不创建第二工作空间；目录路径为只读展示 |
| 语音转写 | 「阿里云百炼 · Qwen-Audio 3.1 · 北京地域」只读说明；API Key 输入/已配置/更换；获取 API Key 链接 | 唯一需要输入的云服务配置为 Key；服务地域华北 2（北京）、模型 `qwen-audio-3.1-asr-flash-filetrans` 内部固定 |

- 三个分区**纵向排列于同一页**，不拆「通用 / 外观 / 存储 / 语音」多级设置导航；无需额外选项卡。
- 设置打开时，保留进入前的业务导航状态（含标签视图、Note/Task 打开上下文），返回时恢复；必须复用已有草稿离开保护，不能使设置导航造成未保存内容丢失。对编辑中的 Note 尽量恢复原来的滚动位置与光标；无论组件是保留挂载还是重建，至少保证回到同一 Note、草稿不丢失，不强求复杂的跨页面光标历史系统。
- 设置仅迁移现有主题和 Vault 的**操作入口**，不改变其业务含义；避免复制两套控制组件导致状态不一致。

## 二、侧边栏收敛与例外

- `frontend/src/App.tsx` 当前侧边栏底部有主题切换按钮、Vault 路径下拉菜单与异常提示。阶段 10 将**主题切换和 Vault 配置操作**移进设置页；移除原主题三按钮与日常 Vault 配置下拉菜单，保留单个设置齿轮。
- **首次启动/未配置 Vault**：现有主内容区仍可直接选择/打开 Vault，不能要求用户先进入设置；设置页存储区也可选择目录。
- **Vault 无法打开、重新扫描失败、索引解析/失效引用等健康异常**：主界面仍有可见的精简状态指示或告警入口，**点击直接打开既有 Vault 健康/错误详细视图**；需更换目录或重扫时才进入设置页。不得仅在设置页深处呈现，也不能因移除 Vault 菜单而丢失现有健康详情。
- Vault 更换成功后正确刷新现有 Note/Task/Activity/Files 索引和界面；更换失败保留旧 Vault 状态及解释性的错误。更换目录不能静默删除原用户资料；已有编辑草稿须遵守离开/冲突保护。
- 「重新扫描」是从磁盘刷新可重建索引，不能删除原始 Note/Activity/附件；扫描过程有忙碌态，错误可以回查。
- 「在 Finder 中打开」仅对已存在且可访问的当前 Vault 提供系统操作，未设置或路径无效时给出提示；不引入 Finder 嵌入式文件管理页面。
- 不改变 Today / Tasks / Notes 三主导航、标签区、全局搜索、Notes 列表与编辑区域布局。

## 三、主题偏好

- 明暗模式保持 `system`、`light`、`dark` 三种；交互强调色可使用默认配色或自定义 RGB。
- 首次没有保存值时默认「跟随系统」；保存为**应用级偏好**，不写入业务 Markdown，也不绑定具体 Vault（更换 Vault 不改变主题）。
- 系统主题变化时，跟随系统状态同步应用；手动浅色/深色时不被系统主题变更覆盖。
- 页面进入时正确展示当前选择；从旧版侧边栏按钮迁移后要保留当前会话状态，并按新偏好机制持久化，避免视觉闪烁。

## 四、API Key 与固定 ASR 配置

| 场景 | 行为 |
|---|---|
| 未配置 | 密码输入 `sk-...`、保存按钮及「获取 API Key」链接；输入不能为空，Key 不进入应用日志 |
| 保存成功 | **Keychain 写入成功后**展示「已配置」，不回显完整旧 Key |
| 更换 | 显式进入新 Key 输入状态，保存成功后替换 Keychain 对应条目；失败则保持旧值 |
| 缺 Key 发起音频转写 | 阶段 11 引导进入同一页的语音转写分区；完成配置后可返回原始 Notes 流程 |
| Key 无效/额度不足 | 保存不冒充连通性校验；阶段 11 调用返回具体鉴权/额度错误，不额外增加「测试连接」 |

- macOS Keychain 按固定服务名/账号标识保存一条密钥；与 Vault 无关。Keychain 拒绝访问、读取或写入错误必须明确提示。
- Go Core 提供最小操作，如查询是否配置、更新 Key、转写内部读取 Key；React/Wails 前端仅得到配置状态，不能读取已保存的明文 Key，也不持久化输入。
- 密钥不写入 `.pata/`、`notes/`、`files/`、业务 Markdown、浏览器 LocalStorage 或日志；禁止记录网络 Authorization 头。
- 阿里云百炼**华北 2（北京）**地域及 `qwen-audio-3.1-asr-flash-filetrans` 模型为内部固定值，接口以实现时官方文档为准；不提供地域下拉、模型切换、自定义 endpoint、热词或多供应商凭证管理。

## MCP

设置页提供服务启停、运行状态、错误提示和接入说明复制。服务使用 Streamable HTTP，仅监听 `http://127.0.0.1:17373/mcp`。

首次默认关闭。启用选择保存在应用配置中，重启后自动恢复，手动停止后保持关闭。启动失败时可重试或取消自动启动。退出 Pata 后服务停止。关闭状态保存失败时，服务仍会停止，设置页提示下次启动可能自动恢复。

| 工具 | 功能 |
|---|---|
| `pata_search` | 搜索任务、笔记、记录和附件名称 |
| `pata_list` | 列出任务或笔记的 ID、标题和标签 |
| `pata_read` | 按 Task ID 或 `pata://task/{id}` 读取任务，按 Note ID 读取笔记，按日期读取每日计划 |
| `pata_create_note` | 创建笔记，设置标题、正文和标签 |
| `pata_create_task` | 创建任务，设置标题、状态、到期日和标签 |
| `pata_append_activity` | 向任务或指定日期追加记录 |
| `pata_set_task_status` | 输入 `{id, status: "done" 或 "todo"}`，完成或重新打开既有任务，返回当前 Task |

### Task URI 与 Agent 协作

任务详情仅在 **MCP 已启用、服务运行中且 Vault 未切换** 时显示「··· → 复制给 Agent」，复制 `处理这个 Pata 任务：pata://task/{id}`；复制前会先保存任务属性与描述的未保存修改，并等待正在进行的任务保存；保存失败或发生冲突时保留草稿与原有错误，停止复制。菜单打开时刷新 MCP 状态，保存完成后再次验证服务可用，避免刚停止服务时复制出无法使用的指令。不要求用户再次输入任务标题、描述或 MCP 名称。这个 URI 是稳定的 Task 引用，不依赖文件路径；**不是** macOS URL Scheme，也不负责启动 Agent。

MCP 注册只读 Resource Template `pata://task/{id}`（JSON），同时兼容通过 `pata_read({kind: "task", id: "pata://task/..."})` 读取；原有 Task ID 仍可用。两种读法均经过同一个 Core、当前 Vault 与 MCP 的访问检查。不存在的 Task 返回读取错误，不自动按名称重定向；Vault 切换后需重新启用 MCP。

`pata_read(kind=task)` 返回完整 Task（包括 Activity 的 `note_refs`）；Agent 可以按需用 `pata_read({kind: "note", id: "n-..."})` 继续读取被引用笔记的正文。Note 引用由稳定 Note ID 绑定；PDF/PPT 等附件使用相对路径，**本次不新增二进制附件读取**。没有显式 `note_refs` 绑定的 `[[名称]]` 不能臆测为某个 ID，应另行查询。

Server Instructions 轻量指导 Agent：发现阶段只看摘要、一个执行 Session 聚焦一个 Task、按需读取关联笔记、Activity 记录结果与后续步骤而不是聊天日志。它是软约束；Pata 不托管 Session、调度 Agent 或强制限制 Activity 长度，不新增 Agent 设置页面或任务字段。没有要求时不自动将任务标记完成。

MCP 创建 Task / Note、追加 Activity 和变更 Task 状态均由 Core 标记 Agent 来源，调用参数不能指定 `created_by` / `by`。来源格式以 [Schema](../02-foundation/schema.md#操作来源阶段-14) 为准。`pata_set_task_status` 重复设置相同状态不写盘、不新增事件；非法状态、缺失任务及未打开或已切换的资料库均返回错误，成功后通知 GUI 刷新。

列表和搜索默认每页 50 条，最多 200 条；`next_offset` 为 `-1` 表示结束。创建与追加不支持幂等重试，连接中断后应先查询结果。

服务绑定启动时的资料库。切换资料库后，旧服务拒绝数据操作，需停止并重新启动。数据读写沿用现有 Markdown 格式，写入后同步更新界面。

## 自定义 RGB 强调色

- 在「设置 → 外观」使用颜色选择器或 R/G/B 输入，数值范围为 0–255；修改立即预览并自动保存，保存失败可重试。
- 自定义颜色作用于导航、按钮、链接、焦点和选中态；自动派生深浅色阶。品牌图标、完成与连接状态、警告及错误保留独立颜色。
- 「恢复默认颜色」清除自定义偏好，恢复现有默认交互配色；明暗模式及 Vault 更换保留自定义颜色。
- 偏好存入应用配置的可选 `accent_color` 字段，格式为六位十六进制 RGB；默认值为空并省略该字段，兼容旧配置。只保存已成功写入的本地缓存，启动时以应用配置为准。
- 颜色设置不修改任务、笔记、日计划、附件或 Keychain。
